Setup

Up and running
in minutes.

🪟 Windows

  1. Open cmd or PowerShell.
  2. Install Python:
    winget install Python.Python.3
  3. Install VLC:
    winget install VideoLAN.VLC
  4. Install dependencies:
    pip install -r requirements.txt
  5. Launch NovaX7:
    python NovaX7_7_1_0.py

🍎 macOS

  1. Open Terminal via Spotlight.
  2. Install Homebrew:
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. Install Python, VLC & deps:
    brew install python --cask vlc && pip3 install PyQt6 PyQt6-WebEngine python-vlc mutagen yt-dlp imageio-ffmpeg pypresence
  4. Right-click project folder → New Terminal at Folder.
  5. Launch:
    python3 NovaX7_7_1_0.py
