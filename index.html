Simple Deployment Framework.

Initialize the Python suite on your system using deployment steps below.

🪟 Windows Setup

  1. Open command prompt terminal console (`cmd`).
  2. Deploy standard Python engine: 
    winget install Python.Python.3
  3. Install core VideoLAN VLC client player binary: 
    winget install VideoLAN.VLC
  4. Install the explicit program framework dependencies: 
    pip install PyQt6 python-vlc mutagen yt-dlp imageio-ffmpeg pypresence
  5. Boot up the main software package application matrix: 
    python NovaX7_7_1_0.py

🍎 macOS Setup

  1. Launch Mac Terminal environment console using Spotlight search.
  2. Inject Homebrew package manager dependencies tools: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. Pull the system configuration runtimes and script engines: 
    brew install python --cask vlc && pip3 install PyQt6 python-vlc mutagen yt-dlp imageio-ffmpeg pypresence
  4. Right-click target program folder, choose **"New Terminal at Folder"**.
  5. Initialize program application script runtime execution: 
    python3 NovaX7_7_1_0.py
