Simple Step-by-Step Setup.

Configure NovaX7 on your environment. Built exclusively for PC & Laptop system execution.

🪟 Windows Setup

  1. Open your system console command prompt (`cmd`).
  2. Install Python environment: 
    winget install Python.Python.3
  3. Install VLC Media Player (from videolan.org or via prompt): 
    winget install VideoLAN.VLC
  4. Open your extracted folder directory in terminal and install requirements: 
    pip install PyQt6 python-vlc mutagen yt-dlp imageio-ffmpeg pypresence

    (Optional for media browser): `pip install PyQt6-WebEngine`

    Shortcut: Or hit Win + R and run `pip install -r requirements.txt` directly inside the folder.

  5. Launch NovaX7 application client: 
    python NovaX7_7_1_0.py

🍎 macOS Setup

  1. Open system Spotlight Search (`CMD + Space`) and launch your **Terminal**.
  2. Install the Homebrew package manager tool setup: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. Download Python environment, VLC player cask, and dependencies: 
    brew install python --cask vlc && pip3 install PyQt6 python-vlc mutagen yt-dlp imageio-ffmpeg pypresence
  4. Open Finder, navigate to your Nova folder directory, right-click and click **"New Terminal at Folder"**.
  5. Initialize the software program script: 
    python3 NovaX7_7_1_0.py
